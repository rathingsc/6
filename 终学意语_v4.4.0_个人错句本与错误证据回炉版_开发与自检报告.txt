终学意语 v4.4.0 个人错句本与错误证据回炉版
开发与自检报告

一、版本目标
把真实写作、自由会话、听写等模块里的错误从“只做统计”升级为“必须重新做对一次才算修复”的长期学习证据，形成错误 -> 回炉 -> 修复 -> 句子FSRS再复习的闭环。

二、核心改动
1. 新增个人错句本 ErrorEvidenceRepairFragment。
2. 每条待修复证据保存：来源模式、目标表达、用户原错误表达、错误原因/细节、修复次数、修复时间。
3. 点“不会·显示正确表达”不算修复，证据继续留在队列。
4. 用户重新输入达到匹配线后才标记修复，并将目标句写入 Sentence FSRS recall 维度。
5. 同一次真实作答若同时触发多个错误原因，错因仍分别统计，但待修复队列按 mode + expected + actual 自动合并，只需真正修复一次。
6. 真实写作失败保存参考正确表达，不再把题目ID当作 expected。
7. 自由会话中未表达清楚或存在明显语法问题的句子会进入错句本。
8. 每日智能计划读取待修复错句；达到阈值时自动调度，且继续遵守每日总时间预算。
9. 练习中心、薄弱项中心、今日总结增加错句本入口及待修复数量。
10. Room 数据库 v5 -> v6，新增 repairedAt、repairAttempts 及迁移 SQL。
11. JSON 学习进度备份格式升级到 version 26，并恢复上述修复字段与待修复计数。
