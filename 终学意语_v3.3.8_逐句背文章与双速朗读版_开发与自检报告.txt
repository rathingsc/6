本版核心开发
------------
1. 十篇通关新增“逐句背文章”模式。
   - 10篇 / 50小节保持不变。
   - memory_articles.json 新增 269 组中意逐句对齐句对。
   - 每小节约 3-7 句。

2. 每句话采用4轮主动记忆：
   - 第1轮：双语理解
   - 第2轮：听读，只看意大利语
   - 第3轮：挖空回忆，优先挖本节目标词
   - 第4轮：只看中文，主动说出整句意大利语

3. 双速朗读：
   - 正常朗读：1.00x TTS
   - 慢速朗读：0.70x TTS
   - 逐句模式和原有整节5步背诵都支持正常/慢速。

4. 本句重点词：
   - 自动从本节40个目标词中识别当前句实际出现的词。
   - 显示意大利语 + 中文，最多6个，帮助把目标词与语境绑定。

5. 真正背文章：
   - 逐句完成后可继续“整节5步背诵”。
   - 也可直接进入本节40个新词 + 旧词的四模式智能复习。
   - 阅读/逐句完成只记录文章接触，不直接伪造四维掌握度。

6. 进度保存：
   - 新增 memory_article_sentence_done_*。
   - 逐句完成状态加入学习进度 JSON 导出/导入。
   - 备份版本升级为 21。
   - 本篇小节卡会显示“逐句背诵 ✓”。

7. 中意句界精校：
   - 原50小节中有9处中文把两个意大利语句子合并成一句，本版重新拆开。
   - 保持原意，并修正部分更准确的表达，例如 un'amica 使用“女性朋友”。

8. 新增发布门禁：
   - tools/memory_article_sentence_quality_check.py
   - 检查50小节、269句对、四轮逐句模式、正常/慢速TTS、MainActivity导航、进度备份和布局。
   - Codemagic 已加入该检查步骤。
