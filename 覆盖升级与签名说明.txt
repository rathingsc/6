终学意语 v5.0.1 固定签名覆盖升级说明

目标
----
继续沿用 v3.1.3 起建立的永久签名链。v5.0.1 只修复课程跨单元重复出词，不修改 applicationId、Room 数据结构或学习备份结构，因此已经安装固定签名版的手机可以继续直接覆盖升级。

Codemagic 必须保持的签名配置
----------------------------
Keystore Reference：zhongxue_release
applicationId：com.italiano2774.nativeapp
正式产物：app/build/outputs/apk/release/app-release.apk

绝对不要做的事
--------------
1. 不要修改 applicationId。
2. 不要丢失或更换 zhongxue_release 对应的永久密钥。
3. 不要重新生成另一把密钥来打正式 APK。
4. 不要把 .jks、.keystore、密码、私密 keystore.properties、.p12 或 .pfx 上传到 GitHub。
5. 不要把 debug APK 与固定签名 release APK 混作正式升级包。

版本与数据兼容
--------------
- v5.0.1：versionCode 81，versionName 5.0.1-native。
- 学习进度 JSON backup version 31。
- Room database version 6。
- v5.0 简洁首页、v4.9 四维单词日程、个人遗忘画像以及更早版本进度继续兼容。
- 本次没有新增持久化字段；只是把跨单元到期复习从固定课程移回专门复习路线。

如何确认签名没有变化
--------------------
Codemagic 构建会生成 signing-fingerprint.txt，并与仓库里的 signing-certificate-sha256.txt 进行比对。所有正式版本的 SHA256 证书指纹必须保持一致；如果指纹变化，应停止安装并检查 Codemagic 签名配置。
