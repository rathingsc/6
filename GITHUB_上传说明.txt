【v3.1.4 构建修正】
某些通过网页/文件管理器上传 GitHub 的方式可能漏掉隐藏文件 .gitignore。
从 v3.1.4 起，Codemagic 不会仅因为 .gitignore 缺失而停止构建；
但项目仍会直接扫描并禁止 *.jks、*.keystore、keystore.properties 等私密签名文件进入仓库。
建议仍将本项目自带的 .gitignore 一并提交。
