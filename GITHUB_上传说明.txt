终学意语 v3.1.0 智能记忆版 GitHub 根目录上传说明

本版属于大型课程重构。为避免过去出现“新旧源码混用”，不要使用旧的 v2.x 小补丁。

推荐方案 A（保留 GitHub 现有 2774 个 MP3）：
1. 下载“v3.1.0 智能记忆版 强制源码同步包 保留2774音频”。
2. 解压。
3. 把解压后的 app/、tools/、build.gradle、settings.gradle、gradle.properties、codemagic.yaml、README 等直接覆盖 GitHub 仓库根目录。
4. 保留现有 app/src/main/assets/audio/。同步包本身不包含 audio 文件夹。

方案 B（最稳）：
清空 GitHub 仓库内容后，解压并上传“v3.1.0 智能记忆版 GitHub根目录完整项目”的全部内容。

GitHub 仓库根目录必须直接看到：
app/
tools/
build.gradle
settings.gradle
gradle.properties
codemagic.yaml
README_原生安卓版本.md

不要多套一层 v3.1 文件夹，不要只把 ZIP 文件提交到 GitHub。

必须确认：
app/build.gradle
  versionCode 41
  versionName '3.1.0-native'

app/src/main/java/com/italiano2774/nativeapp/SmartMemoryScheduler.java
  必须存在，负责 1 / 3 / 7 / 15 / 30 / 60 天智能复习间隔

app/src/main/res/layout/fragment_course_home.xml
  必须包含 button_smart_memory 和 text_smart_memory_summary

app/src/main/assets/course_curriculum.json

  A0 8 / A1 24 / A2 30 / B1 36

app/src/main/res/menu/menu_bottom.xml
  只有 学习 / 课程 / 练习 / 我的 四个底部入口

codemagic.yaml
  工作流名称必须包含 v3.1
  必须包含 Guided course semantic checks
  必须包含 Strict release gate

Codemagic 正常顺序应为：
Set Android SDK location
Create Gradle wrapper
Preflight project checks
Static regression checks
Guided course semantic checks
Exercise quality checks
Strict release gate
Build native debug APK
Unit tests
Android lint report

如果 Build native debug APK 出现在第 4 步左右，说明 codemagic.yaml 仍然是旧版本，不要继续用那个仓库状态构建。
