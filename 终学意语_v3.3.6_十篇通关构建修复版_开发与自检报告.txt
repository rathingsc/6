本次真实构建错误
--------------
Codemagic 在 :app:compileReleaseJavaWithJavac 阶段失败：
CourseHomeFragment.java 的 renderMemoryArticles() 把中文摘要跨源码行直接写进普通 Java 双引号字符串，导致 unclosed string literal，后续中文标点被 Java 编译器连锁识别为 illegal character / not a statement。

修复
----
1. 将该摘要的源码换行改为 Java 转义 \n：
   "...四维掌握 "+mastered+"\n每篇200个目标词..."
2. 保留十篇通关首页摘要原本的两行显示效果。
3. 新增 tools/java_source_syntax_check.py。
4. Codemagic 在 Preflight 后、其他静态检查前执行 Java source literal checks。
5. 检查全部 Java 文件的普通字符串、字符字面量、块注释是否存在非法原始换行或未闭合情况。
6. Preflight、Regression、Strict Release Gate 均要求新的 Java 源码检查步骤存在，避免以后上传混合旧文件时漏掉。
