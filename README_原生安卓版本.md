# 终学意语 v3.0 多邻国式循序课程版

本版不是继续增加工具，而是重构“每天怎么学”。主界面改成唯一学习路径：A0 → A1 → A2 → B1，一关一关解锁；单词、句子、听力、复习和主动回忆在 3–7 分钟短课里自动混合。已有 2774 词、FSRS、四维掌握、错题诊断、听力、阅读、语法、Room 数据和备份全部保留，但高级机制默认藏在后台。

## v3.0 核心变化
- 新增固定课程资产 `course_curriculum.json`：98 个连续单元，A0 8 / A1 24 / A2 30 / B1 36，2774 个词条每个恰好归入一个单元。
- 课程累计词量：A0 186；A1 完成后累计 855；A2 完成后累计 1576；B1 完成后 2774。

- 新词难度渐进：先认识 → 词义选择 → 听音 → 补拼写/句子 → 主动写出；不会第一次见词就要求完整输出。

- 单元挑战正确率达到 70% 后解锁下一单元；失败不会扣已有进度，可直接重试。
- 学习中断 36 小时内可从同一题继续。
- 水平测试可以把路径向前推进；不会因为 v3 初始化过早而强制从 A0 重学，也绝不会把已有路径向后退。
- 练习页初始只显示：听力、发音、错题、拼写。句子、场景、短语、语法、动词、阅读、弱项分析随着课程逐步解锁。
- “我的”集中词库、日报、周报、设置、自定义词句、数据库与备份。
- 首次引导只问学习目的和每天 10/20/30/45/60 分钟，系统自动推荐 5/10/15/20/25 个新词节奏。
- 保留旧版高级学习能力和数据兼容；升级前继续创建本地恢复点，Room 仍保持 v5 非破坏性迁移。
- 新增 `tools/course_check.py`，专门验证 98 单元顺序、2774 词覆盖、短课容量与源课程顺序。
