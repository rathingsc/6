# 终学意语 v5.0.1 课程跨单元重复修复版

## v5.0.1 修复“同一个词几乎每个单元都出现”

用户实机反馈 `prenotazione`（预约；预订）会在很多与“披萨店/预订”无关的 A2、B1 单元重复出现。全量审计确认：固定课程资产本身没有重复分配——98 个单元正好分配 2774 个词，每个词只属于一个单元；`prenotazione`（id 716）只属于 `A1-U19 披萨店`。

根因在 `CourseLessonEngine`：旧逻辑会在每节固定课程末尾额外调用全局 `reviewDue()`，并且故意排除当前单元词，再把一个其他单元的最早到期词塞进课程。因此只要某个顽固词长期到期，它就会跨主题连续污染很多单元。

v5.0.1 改为：

- 固定 98 单元 **禁止跨单元注入全局到期词**；
- 课程内仍保留 `addSeenReinforcement`，只复现本单元前面已经学习过的词；
- 单元挑战也只从本单元 `wordIds` 取目标词；
- 全局到期复习没有删除，继续由“今日智能计划 / 到期复习 / 5分钟抢救 / 四维遗忘模型”处理；
- 新增 `tools/course_unit_isolation_quality_check.py`，强制检查 98 单元 / 2774 词一一归属，以及课程引擎不得重新调用 `reviewDue()`；
- 新门禁已接入 Preflight / Regression / Strict Release Gate / Codemagic。

# 历史版本 v4.9.0 四维个人遗忘模型版

## v4.9.0 同一个词不再只有一个复习日期

这一版把原来的“一个单词一套总复习日程”升级成真正的 **识义 / 听力 / 拼写 / 口语四条独立记忆轨道**。一个词可能已经很熟悉中文意思，但仍然听不出来、拼不出来或说不出来；v4.9 会分别预测这四条通道什么时候开始遗忘，并把当天真正到期的能力自动变成对应题型。

### 四条独立记忆轨道

每个已经学习的单词现在可以分别保存：

- 上次复习日期
- 当前稳定度
- 当前难度
- 当前复习间隔
- 下一次到期日期

四条轨道互不串改。例如今天只练了 `biglietto` 的听力，系统只推进“听力”日程，不会顺手把识义、拼写和口语也延后。

### 旧用户安全迁移

为了避免升级后 2774 个词突然全部到期，v4.9 保留旧版总日程作为兼容层。某个旧词第一次进入四维调度时，系统先把旧总日程冻结复制到该词已经建立的能力轨道，再只更新本次真正训练的那一条。

因此：

- 旧学习进度不会清零；
- 不需要重新学已经学过的词；
- 不会因为第一次练识义就污染听力/口语的历史日期；
- 后续使用中四条曲线会逐渐分化成真正属于用户自己的节奏。

### 到期复习自动换题型

“到期复习 / 5分钟抢救 / 智能背词”会先判断当前词真正到期的是哪条通道：

- 识义到期 → 词义主动提取；
- 听力到期 → 听音识词；
- 拼写到期 → 拼写/听写；
- 口语到期 → 只看中文主动说。

同一个词不再因为“总日程到期”而总是重复考中文释义。

### 个人遗忘节奏校准

在单词自己的 FSRS 卡片调度之外，v4.9 新增一层温和的个人通道校准：

- 前 5 次有效复习主要收集证据；
- 如果系统预计“还记得”但用户实际已经忘了，该通道未来间隔会略微缩短；
- 如果已经拖得较久仍能稳定答对，该通道未来间隔会略微拉长；
- 校准系数限制在 **0.70～1.30**，不会盖过每个词自己的 FSRS。

因此系统可以逐渐发现：某个用户可能“识义保持很稳，但口语忘得快”，另一个用户则可能“听力最脆弱”。

### 新增个人遗忘画像

“我的”页面新增 **🧠 个人遗忘画像**，分别显示四条通道的：

- 今天到期数量；
- 平均复习间隔；
- 当前平均保持率；
- 个体遗忘速度；
- 已累计多少次有效校准证据。

今日学习总结也直接显示“识义 / 听力 / 拼写 / 口语”今天各有多少条到期。词库详情可以看到单个词四条轨道各自的下一次复习日期。

- 旧版备份没有 `dimensionSchedules` 时仍可按旧总日程恢复；
- v4.9 备份新增 `dimensionSchedules` 与 `forgettingProfile`；
- `repairCorruptState` 已加入四维间隔、稳定度、难度和个人校准系数的异常值修复。

## v4.7.0 把“今天正在忘的词”重新放回真实语境

这一版不联网生成意大利语，也不凭模板硬拼句子。系统会先读取当前学习状态，从**已学词**里按照错词、顽固词、到期/逾期、四维最低项和记忆保持率筛出当前最值得巩固的词，再优先从已经审校的**十篇通关文章**中选择上下文最完整、与这些薄弱词重合最高的小节；如果当前弱词不在十篇覆盖范围，则退回 2774 词库中已有的**已审校例句**。

核心训练固定四步：

- **第1步 · 先读懂**：显示完整意大利语短文，重点关注系统筛出的约 **6～10 个**当前薄弱/到期词；中文默认不强制显示。
- **第2步 · 不看文字听**：正文暂时隐藏，至少完整听一遍；提供 **0.70× / 0.92×** 两档速度，防止“只靠眼睛认得”。
- **第3步 · 听后挖空**：从原文里抽最多 4 个稳定可识别的重点词，按顺序填写。一次作答同时训练**听力 + 拼写**，但 FSRS 日程只推进一次，避免同一题重复拉长间隔。
- **第4步 · 只看中文复述**：隐藏意大利语，只保留中文，用自己的意大利语复述主要意思并尽量主动用上今日重点词。通过线 **60%**；第一次未通过可再试一次，第二次才作为当日正式结果。

## 历史版本 v4.4.0 真实错误必须重新做对，才算真正修复

这一版不再把写作、自由会话、听写里的真实错误只留在统计里，而是统一进入「个人错句本」。每一次真实作答只形成一条待修复证据：保留你当时说/写的错误表达、目标正确表达、错误原因与来源场景。即使一次作答同时触发漏词、拼写、冠词等多个错误原因，回炉队列也会自动合并，不会让同一句重复出现多次。

核心规则：
- 点「不会 · 显示正确表达」只算一次暴露/复习，**不算修复**。
- 必须自己重新输入，并达到当前任务匹配线，才会标记为已修复。
- 修复成功后，正确表达进入句子 FSRS，之后继续按间隔出现，而不是修完一次就永久消失。
- 真实写作失败现在保存可复习的参考表达，不再只保存题目 ID。
- 自由会话中「意思未表达清楚」以及「能听懂但存在明显语法问题」都会留下可回炉证据。
- 每日智能计划会读取待修复错句数量；积压达到阈值时自动插入「个人错句本」，并继续受 10/20/30/45/60 分钟总预算约束。
- 只有真正修复成功的错句才计入当天该任务完成；仅查看答案不会把每日任务标成完成。
- 练习中心、薄弱项中心、今日总结均新增错句本入口和待修复数量。
- Room 数据库升级到 v6，持久保存 `repairedAt` 与 `repairAttempts`。
- 学习进度 JSON backup version 升级到 26，覆盖升级/备份恢复继续保留修复状态。

# 终学意语 v2.3 · 语言结构深化版

这是在 v2.2「学习质量与稳定性版」基础上继续开发的原生 Android 版本。v2.3 **不接入任何生成式 AI / 大模型 API**，新增功能全部在本地课程数据、规则与已有学习记录上运行。

## v2.3 新增

### 1. 单词词族 / 词形家族
- 新增 `word_families.json`，当前整理 **239 组**高置信度词族或词形家族。
- 包括同一动词原形的课程变位、名词单复数，以及课程中确实存在的派生词族。
- 例如 `parlare / parlo / parli / parla / parola / parole`、`lavoro / lavorare` 等。
- 点击成员可直接听意大利语发音。
- 课程词卡展开后也会显示所属词族，帮助把孤立词连接起来。

### 2. 完整动词中心
- 自动整理课程中约 **220 个动词原形**。
- 支持 5 个核心时态：
  - Presente 直陈式现在时（A1）
  - Passato prossimo 近过去时（A2）
  - Imperfetto 未完成过去时（A2）
  - Futuro semplice 简单将来时（B1）
  - Condizionale presente 现在条件式（B1）
- 高频不规则动词、未来词干和过去分词做了本地规则/词表处理。
- 内置「变位快练」，错误会进入现有错误原因系统中的“词形/变位”类别。

### 3. 语法知识地图
- 按 A1 / A2 / B1 分层展示核心语法点。
- 根据真实练习次数与正确率显示：未开始、优先补、需要巩固、基本稳定。
- 每个语法点可直接跳到对应训练。
- v2.3 将句型库从 21 个扩展到 **27 个**，新增：
  - Futuro semplice
  - Condizionale presente
  - 直接宾语代词
  - 间接宾语代词
  - Imperativo 命令式
  - 代词 ne

### 4. 智能完形填空（无 AI）
- 完全本地运行，不调用大模型。
- 约 2/3 题目来自用户当前最弱语法，约 1/3 来自低掌握度课程词的真实例句。
- 答错后自动更新语法错误、拼写弱项和自适应学习路径。
